# **NexMedia Web Image Optimiser**



A lightweight batch image optimiser designed for web use. Easily convert unoptimised images into suitable formats (mainly WEBP) all in one place.





## **Features**



* Batch import individual images or entire folders.
* Supports JPEG, PNG, WebP.
* Convert to WEBP or PNG (PNG is lossless and no compression is applied).
* Automatically chooses an optimal compression level based on the target dimensions and file size limit (WEBP only).
* Does not modify or overwrite original images.
* Automatic app updates and release notes section.
* Common web image dimensions provided as presets.
* Settings and help page.





## **Download**



1\. Find the latest version from the **Releases** page.

2\. Download **NexMedia.WebImageOptimiser-win-Setup.exe** if you are on a Windows machine.

3\. Run `Setup.exe` to install the application.


NexMedia Web Image Optimiser is currently built for Windows x64.





## **Usage**



1\. Import images or a folder.

2\. Select the images you want to process.

3\. Configure resize and optimisation settings.

4\. Optimise the selected images.

5\. Review the results and export them.



More detailed instructions are available from the built-in **Help** page.





## **Privacy**



Image processing is performed locally on your computer. Images are not uploaded to an external service as part of the optimisation process. Internet access is only required for features such as update checking and release notes.





## **Updates**



The application periodically checks GitHub for new stable releases. Available updates are downloaded automatically and installed when the application is restarted. You can manually check for updates in the app.





## **Development Notes**



The project is built with C#, .NET and WPF, with VeloPack used for installation and application updates. Additional development and release documentation is available in the repository.
